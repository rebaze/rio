# Rio v0.9.0-rc1

**A pre-release that exercises the new release path. Install a stable release for real use.**

This pre-release is built, signed and attested in the `build` job and left there as a draft. The
gated `publish` job checks the draft's digests and bytes again and only then makes it public
([#165](https://github.com/rebaze/rio/issues/165)). The Homebrew cask is not updated for
pre-releases.

It contains what is on `main` for v0.9.0 so far:

- **A build can declare the shipped files.** It lists them under `distributions` in the build
  context file, with name, SHA-256 and optional URL. Rio writes them into the SBOM subject as
  `distribution` references and lists them in the receipt as producer assertions.
  `gate.subject.require: [digest]` blocks delivery without them. OCI delivery stops before any
  request when the image's digest is not among them. Rio never hashes the files
  ([#171](https://github.com/rebaze/rio/issues/171)).
- **Rio can normalize its own output again.** It records itself in `metadata.tools` once per
  version ([#181](https://github.com/rebaze/rio/issues/181)).

Receipts and SBOMs that carry distributions cannot be read by v0.8.2 or older.
