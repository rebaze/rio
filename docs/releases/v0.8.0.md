## What changed

v0.8.0 is a baseline release. Rio's commands, flags, manifest, receipt format and runtime
behavior are the same as v0.7.2; the binary is rebuilt from the same Go source and
dependencies. The repository around it is smaller:

- Removed the feature-video authoring tooling and the Juice Shop walkthrough. The synthetic
  client-record demo above covers the same consumed → enriched → delivered → acknowledged
  workflow without building intentionally vulnerable software or resolving unpinned npm
  dependencies.
- The release-tool build no longer refuses to run when a workflow or release script changes
  by a single byte. Cosign, Syft and GoReleaser are still rebuilt from authenticated upstream
  modules with locked dependencies, scanned with symbols, and refused on any unreviewed
  advisory. Routine GitHub Actions updates no longer fail CI on that check.
- Removed a one-off workflow that only smoke-tested the release App token.
- Updated CodeQL, `upload-artifact` and `download-artifact` action pins.

Every remaining feature demonstration still runs against the built binary in CI on Linux,
macOS and Windows, together with the real OCI and Dependency-Track receivers.
