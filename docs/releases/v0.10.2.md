## What changed

- **Rebuilt with Go 1.27.4**, fixing
  [GO-2026-6859 / CVE-2026-97054](https://pkg.go.dev/vuln/GO-2026-6859) in the Go standard library
  ([#224](https://github.com/rebaze/rio/issues/224)). The advisory describes an HTTP/1 server crash
  involving concurrent request-body reads and response-header writes. Rio uses outbound HTTP
  clients; no matching server-side path was identified in Rio's production code.

## Build maintenance

CI and release builds automatically select the latest patch within the reviewed Go 1.27 line.
Regression checks guard that selection and run before CI change filtering. A new Go minor line
still requires an explicit change. The incident and operational follow-ups are recorded in
[#226](https://github.com/rebaze/rio/issues/226).

## Compatibility

CLI behavior, manifests, receipts and delivery formats are unchanged. Upgrade the installed binary
to receive the patched runtime; merging the source fix does not update existing installations.
