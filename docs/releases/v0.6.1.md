# Rio v0.6.1

See what Rio produces before configuring a server. The README and these notes now lead with a real
client record, its before/after report, and downloadable examples generated by the released binary.

## See the record

Two commands produce normalized SBOMs **and one portable record explaining the work**:

```sh
rio normalize --gate fail && rio deliver --evidence target/rio/record.json
rio record report --file target/rio/record.json --output target/rio/report.html
```

## What changed

The first example now comes before setup: a real repair table, full inspectable JSON, and an offline
HTML report. The README also identifies v0.6.0 as the minimum version for automatic collection and
HTML reports. CLI behavior and record formats are unchanged from v0.6.0.

The sample was produced by the published v0.6.0 binary against a synthetic receiver, then inspected
and rendered offline. It contains two selected artifacts, three accepted acknowledgments and one
excluded pair. The full installed-binary demo also checks partial responses, exceptions and tamper
refusal. Record consistency is not authenticity, and acknowledgment is not ingestion proof.
