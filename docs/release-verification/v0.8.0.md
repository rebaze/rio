## Scope

v0.8.0 is the baseline release from [#139](https://github.com/rebaze/rio/issues/139).
Its Go source, module requirements, GoReleaser configuration and installer are
identical to v0.7.2; the binary differs in its embedded version, commit and date.
Rio and the release tools were built with Go 1.27.2. The release-tool audit retains
GO-2026-5932 and GO-2026-6225 as narrowly reviewed unused-feature dispositions;
these are not declarations that the tools are vulnerability-free.

Apple notarization [#17](https://github.com/rebaze/rio/issues/17), Artifactory validation
[#88](https://github.com/rebaze/rio/issues/88) and badge registration
[#37](https://github.com/rebaze/rio/issues/37) remain separate follow-ups. Synthetic
receiver acknowledgments do not establish ingestion or long-term retention.
